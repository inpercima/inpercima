# Agent instructions

This repository generates a dashboard for the public GitHub repositories of `inpercima`.

## Project reference

- Read `README_PROJECT.md` for the project structure, feature details, data sources, and health-score rules.
- `README.md` is generated by `dashboard.mjs`; avoid editing its generated dashboard content by hand.

## Development

- The project uses JavaScript ES modules and requires Node.js `>=24.16.0`.
- Run the test suite with `npm test` (`node --test`).
- Tests are in `test/`; update or add focused tests when changing dashboard or scoring behavior.
- Run `node dashboard.mjs` to generate the dashboard. A `GITHUB_TOKEN` is optional, but increases the GitHub API rate limit.
